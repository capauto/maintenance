# CAP AUTO – Carte de visite numérique

Carte de visite interactive pour **CAP AUTO** (Atelier de maintenance automobile – Béjaïa).

## Fonctionnalités

- Design mobile-first inspiré des cartes modernes
- Logo SVG intégré
- Bouton **Enregistrer le contact** (télécharge un fichier vCard `.vcf`)
- Bouton **Enregistrer la page**
- Appel direct
- WhatsApp
- Localisation Google Maps
- QR Code généré automatiquement
- Services affichés (Vidange, Freinages, Lubrifiants, etc.)

## Mise en ligne sur GitHub Pages (gratuit)

1. Créez un nouveau dépôt sur GitHub (ex. `cap-auto`)
2. Uploadez le fichier `index.html` à la racine du dépôt
3. Allez dans **Settings → Pages**
4. Source : **Deploy from a branch** → Branch `main` → dossier `/ (root)`
5. Cliquez sur **Save**
6. Votre carte sera accessible à l’adresse :  
   `https://votre-username.github.io/cap-auto/`

### Alternative rapide (drag & drop)

1. Allez sur [github.com/new](https://github.com/new)
2. Nommez le dépôt `cap-auto`
3. Cochez « Add a README file »
4. Une fois créé, cliquez sur **Add file → Upload files**
5. Glissez le fichier `index.html`
6. Activez GitHub Pages comme indiqué ci-dessus

## Personnalisation

- Modifier le numéro de téléphone, l’adresse ou les services directement dans le fichier `index.html`
- Le QR Code se met à jour automatiquement selon l’URL de la page
